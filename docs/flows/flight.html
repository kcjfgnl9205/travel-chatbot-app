항공권 응답 한눈에

항공권은 검색을 하지 않습니다. 출발지·도착지·날짜·인원을 넣은 예약 사이트 검색 링크를 바로 만들어 줍니다. 그래서 기다림이 없고, 대신 날짜와 공항을 확인하는 단계가 있습니다.

도움말

알아두면 좋은 동작

  • 항공권은 「찾고 있어요」와 「검색 안 됨」이 없습니다. AI 를 부르지 않고 링크만 만들어서 늘 바로 답합니다. 의도 해석에 모델이 필요한 문장만 3.5초를 넘겨 「아직 정리 중이에요 🔍」가 날 수 있습니다.
  • 도시를 두 개 말하면 앞이 출발지입니다. 「오사카 도쿄 항공권」 → 오사카→도쿄. 「에서」를 붙이면 그쪽이 출발지가 됩니다.
  • 만료된 링크를 누르면 「링크가 만료되었어요 · 챗봇에서 다시 추천받아 주세요.」 페이지가 뜹니다.

그 밖의 경우

위 흐름도에 없는 경우를 짧게 모았습니다. 왼쪽이 상황·발화, 오른쪽이 결과입니다. 항공권은 검색 없이 바로 링크를 만들어서 「찾고 있어요」가 없습니다.

⚠️ 헷갈릴 수 있어요

  • 오사카 항공권이랑 호텔
    → 호텔 카드 항공권이 아니라 호텔이 나갑니다. 두 가지를 물으면 하나만 답합니다(호텔 → 항공권 → 관광지 순).
  • A에게 되물었는데 B가 다낭
    → ⑤ 도움말 되묻기는 물어본 사람에게만 이어집니다.
  • 되묻고 5분 뒤 다낭
    → ⑤ 도움말 5분이 지나면 기다리던 질문이 사라집니다.
  • 배포 직후 다낭
    → ⑤ 도움말 재시작하면 기다리던 질문이 사라집니다.
  • 서버에서 오류
    → ⑤ 도움말 말을 잘못한 것처럼 보이지만 서버 문제입니다.

되묻기에 이렇게 답하면

  • 다낭
    → ① 서울→다낭 왕복 링크 출발지는 서울, 왕복으로 봅니다. 다르면 「부산에서 다낭 편도」처럼 다시 물으면 됩니다.
  • 베트남
    → 다시 되묻기 「베트남 어디로 가세요?」 이번엔 도시 버튼 없이 글만 나갑니다.
  • 다른 도시
    → 도시 이름 묻기 「어느 도시 항공권을 찾으세요?」
  • @가자고만
    → 같은 질문 다시
  • 몰라응점심뭐먹지
    → ⑤ 도움말 지명이 아니면 찾지 않습니다. 5분 안에 지명을 말하면 다시 이어집니다.
  • 다낭 가고 싶은데요12월 1일
    → 처음 질문처럼 판단 길거나 숫자·물음표가 있으면 지명으로 안 봅니다.

그 밖에

  • 5초 안에 못 끝냄
    → 「응, 잠시만 기다려 줘.」 카카오 대기 문구입니다. 결과는 자동으로 옵니다.
  • 배포 중 · 앱이 꺼짐
    → 「지금 잠깐 점검 중이에요 🙏」
  • 오래된 카드의 링크
    → 「링크가 만료되었어요」 페이지
말풍선 문구는 코드 그대로이고, 호텔·도시 이름과 날짜는 예시입니다. 실행 화면이 아니라 코드 기준입니다.
