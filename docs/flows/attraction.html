관광지 응답 한눈에

관광지를 물으면 봇은 질문 세 개로 답을 정합니다. 결과는 다섯 가지뿐입니다. 

flowchart LR
  S(["관광지 질문"]) --> Q1{"여행 얘기인가?"}
  Q1 -- 아니오 --> R4["④ 도움말"]
  Q1 -- 예 --> Q2{"어느 도시인지
알 수 있나?"}
  Q2 -- "지명 없음 · 나라만" --> R2["② 되묻기"]
  Q2 -- 예 --> Q3{"그 도시 관광지가
저장돼 있나?"}
  Q3 -- 예 --> R1["① 목록 카드"]
  Q3 -- 아니오 --> R3["③ 찾고 있어요"]
  R2 -. 도시를 고르면 .-> Q3
  R3 -. "다 찾으면 자동으로" .-> R1

⑤ 검색 안 됨은 발화와 상관없이 서버의 DB 가 꺼졌을 때만 나옵니다.

운영 봇은 오픈빌더 폴백 블록의 [콜백 사용]이 켜져 있어서, 검색이 끝나면 카드가 같은 대화에 자동으로 옵니다. 다시 물을 필요가 없습니다. 기다리는 동안 보이는 「응, 잠시만 기다려 줘.」는 서버가 아니라 카카오가 띄우는 대기 문구입니다.

검색 안 됨

서버 문제
이럴 때
사용자 발화와 상관없이 DB 가 꺼져 있을 때만 나옵니다.

다음: DB 가 살아나면 평소대로 돌아갑니다.

가
지금은 오사카 관광지 검색이 안 되고 있어요 🙏 고쳐두는 대로 다시 알려드릴게요.

그 밖의 경우

위 흐름도에 없는 경우를 짧게 모았습니다. 왼쪽이 상황·발화, 오른쪽이 결과입니다.

⚠️ 헷갈릴 수 있어요

  • A에게 되물었는데 B가 방콕
    → ④ 도움말 되묻기는 물어본 사람에게만 이어집니다.
  • 되묻고 5분 뒤 방콕
    → ④ 도움말 5분이 지나면 기다리던 질문이 사라집니다.
  • 배포 직후 방콕
    → ④ 도움말 재시작하면 기다리던 질문이 사라집니다.
  • 오사카 맛집이랑 호텔
    → 호텔 카드 두 가지를 물으면 하나만 답합니다(호텔 → 항공권 → 관광지 순).
  • 서버에서 오류
    → ④ 도움말 말을 잘못한 것처럼 보이지만 서버 문제입니다.

되묻기에 이렇게 답하면

  • 태국
    → 다시 되묻기 「태국 어디로 가세요?」 이번엔 도시 버튼 없이 글만 나갑니다.
  • 다른 도시
    → 도시 이름 묻기 「어느 도시 관광지를 찾으세요?」
  • @가자고만
    → 같은 질문 다시
  • 몰라응점심뭐먹지
    → ④ 도움말 지명이 아니면 검색하지 않습니다. 5분 안에 지명을 말하면 다시 이어집니다.
  • 방콕 가고 싶은데요3박
    → 처음 질문처럼 판단 길거나 숫자·물음표가 있으면 지명으로 안 봅니다.

그 밖에

  • 누가 같은 도시를 먼저 찾는 중
    → 「오사카 관광지를 먼저 찾고 있어요 🔍」 잠시 뒤 다시 물어야 합니다.
  • 5초 안에 못 끝냄
    → 「응, 잠시만 기다려 줘.」 카카오 대기 문구입니다. 결과는 자동으로 옵니다.
  • 배포 중 · 앱이 꺼짐
    → 「지금 잠깐 점검 중이에요 🙏」
  • 결과가 지워진 뒤 더 보기버튼
    → 「가자고가 도와드릴 수 있는 것」 카드
  • 기록이 지워진 링크
    → 「링크가 만료되었어요」 페이지 링크에 유효기간은 없습니다. 데이터 비우기 뒤에 누르거나, DB 조회가 실패했을 때만 나옵니다.
말풍선 문구는 코드 그대로이고, 관광지·도시 이름은 예시입니다. 실행 화면이 아니라 코드 기준입니다.
