# 카카오 오픈빌더에서 해야 할 것

> 코드로는 못 하는 설정만 모았다. **이 문서의 체크리스트가 다 켜져야** 단톡방에서
> "검색중 → 완료되면 카드 자동 도착" 이 동작한다.
> 서버 쪽 구조는 [ROUTER.md](ROUTER.md), 지금 남은 문제는 [HANDOFF.md](HANDOFF.md).

---

## 0. 전제 — 블록을 만들지 않는다

| 항목 | 상태 |
|---|---|
| 시나리오 블록 (호텔검색/항공권검색/여행지검색) | **전부 삭제** |
| 나의 엔티티 (여행도시 등) | **전부 삭제** |
| 대표 명령어 | **전부 삭제** |
| 폴백 블록 | 스킬 연결 + 봇 응답 = 스킬데이터 |
| 봇 입장 · 도움말 블록 | 사용법 안내 문구 |

블록이 하나도 없으므로 **봇을 멘션한 모든 발화가 폴백으로 떨어진다.** 그게 이 구조의
전제다 — 무엇을 묻는지는 URL 이 아니라 발화가 정한다.

⚠️ 블록을 다시 만들면 그 발화는 라우터로 안 온다. "호텔" 이 들어간 발화가 옛 블록으로
새는 식으로 조용히 갈린다.

---

## 1. 스킬 등록 (1개)

**설정 → 스킬 → 생성**

| 칸 | 값 |
|---|---|
| 이름 | `travelmate-router` (아무거나) |
| URL | `https://bot.nolmoa.com/api/v1/kakao/router` |
| 헤더 이름 | `X-Skill-Token` |
| 헤더 값 | 서버 `.env` 의 `KAKAO_SKILL_TOKEN` 과 **똑같이** |

**됐는지 판별**: 스킬 화면의 테스트에서 `{"userRequest":{"utterance":"오사카 호텔
추천해줘"}}` 를 보내면 200 과 함께 `version: "2.0"` 이 온다.
401 이면 헤더 값이 서버와 다른 것이고, 404 면 URL 이 틀렸거나 서버가 옛 버전이다.

```bash
# 서버가 어느 버전인지 밖에서 확인하는 법
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://bot.nolmoa.com/api/v1/kakao/router -d '{}'
# 401 → 새 버전(토큰 검사 중). 404 → 라우터가 없는 옛 버전이 떠 있다
```

## 2. 폴백 블록

**시나리오 → 폴백 블록**

1. **스킬** = 1번에서 만든 `travelmate-router`
2. **봇 응답** = `스킬데이터` ← 텍스트 응답이 아니라 스킬데이터여야 한다
3. **[콜백 사용] 켜기** ← **지금 꺼져 있다. 이게 가장 중요하다** (3장 참고)

⚠️ 봇 응답이 `스킬데이터` 가 아니면 서버가 만든 카드가 버려지고 블록에 적힌 텍스트가
나간다. "카드가 아니라 엉뚱한 안내만 나온다" 면 여기를 먼저 본다.

---

## 3. ⭐ [콜백 사용] — 지금 꺼져 있다

### 왜 필요한가

AI 검색은 **7~75초**가 걸리는데 카카오는 **5초 안에** 응답을 받아야 한다. 그래서 서버는
"찾고 있어요" 를 5초 안에 보내고, 검색이 끝나면 **결과를 나중에 밀어넣는다**.
그 밀어넣을 주소(`callbackUrl`)를 카카오는 **콜백을 켠 블록에만** 실어 보낸다.

```
콜백 켜짐  →  "찾고 있어요. 잠시만요 🔍"  →  (검색 끝)  →  카드가 자동으로 도착
콜백 꺼짐  →  "찾고 있어요 🔍 30초쯤 뒤에 다시 물어봐 주세요!"  →  사용자가 다시 물어야 함
```

### 지금 꺼져 있다는 증거

단톡방에서 받은 문구가 이것이었다:

```
오사카 호텔을 찾고 있어요 🔍
30초쯤 뒤에 다시 물어봐 주세요!
```

이 문구는 **`callbackUrl` 이 안 실려 왔을 때만** 나가는 경로다
([cards.ts](../src/modules/kakao/cards.ts) `searchStartedText`).
켜져 있었다면 `오사카 호텔을 찾고 있어요. 잠시만요 🔍` 가 나왔어야 한다.

### 켜는 법

폴백 블록 화면 → **스킬 선택 아래 [콜백 사용] 토글** → 저장 → **봇 배포**

> ⚠️ 오픈빌더는 **배포를 해야** 설정이 실제 대화에 반영된다. 저장만 하고 배포를 안 하면
> 바뀐 게 없다.

### 켠 뒤 확인

단톡방에서 한 번 물어본다.

| 보이는 문구 | 뜻 |
|---|---|
| `찾고 있어요. 잠시만요 🔍` | ✅ 콜백이 켜졌다 |
| `30초쯤 뒤에 다시 물어봐 주세요!` | ❌ 아직 꺼져 있다 (배포 안 했을 가능성) |

## 4. ⚠️ 켜도 지금은 카드가 안 올 수 있다 (서버 쪽 문제)

카카오는 콜백을 **1분 안에** 받아야 한다. 그런데 현재 검색이 **43~75초**라 그 창을
넘긴다 → 카카오가 콜백을 버린다 → 사용자는 또 못 받는다.

**이건 오픈빌더 설정이 아니라 서버 문제다.** 작업 내용은 [HANDOFF.md](HANDOFF.md) 3-A-2.
그게 끝나면 총 27초 안팎이 되어 콜백이 정상 도착한다.

그때까지는 콜백을 켜도 "다시 물어보면 카드가 나오는" 상태가 이어질 수 있다.

## 5. 봇 입장 · 도움말 블록

사용법 안내 문구를 적어둔다. 서버가 만드는 도움말 카드와 **같은 말**이어야 혼란이 없다.

```
여행메이트예요. 이렇게 물어보세요 👇
🏨 오사카 호텔 추천해줘
✈️ 오사카 항공권 찾아줘
📍 도톤보리 맛집 알려줘

· 날짜·인원은 아직 검색에 반영되지 않아요 (카드 아래에 표시돼요)
· 결과는 AI가 정리한 참고 정보예요
```

## 6. 단톡방 검증 체크리스트

봇을 멘션해서 하나씩 확인한다. **그룹챗봇에서만 생기는 문제**가 세 가지 있어서,
이 목록이 곧 미해결 과제다.

- [ ] **인사말** — `@여행메이트 안녕?` → 도움말 카드 3줄이 뜬다
      (오류 문구가 뜨면 안 된다)
- [ ] **호텔** — `@여행메이트 오사카 호텔 추천해줘` → "찾고 있어요" → **카드 자동 도착**
      · 카드가 자동으로 안 오면 → 콜백이 꺼졌거나(3장) 검색이 1분을 넘긴 것(4장)
- [ ] **⭐ 콜백 푸시가 그룹챗방에서 실제로 도착하는가** ← **아무도 검증 못 한 항목**
      · 안 오면 폴백 블록의 [콜백 사용] 을 **끄는 게 낫다** —
        코드가 자동으로 "다시 물어봐 주세요" 방식으로 돌아간다
- [ ] **⭐ "더 보기" 버튼이 동작하는가** ← **미검증**
      · 눌렀는데 아무 반응이 없으면 서버 `.env` 에 `MORE_BUTTON_STYLE=message` 를 넣고
        `docker compose up -d --force-recreate app`
      · itemCard 가 그룹챗방에서 안 그려졌던 전례가 있어서 `action:"block"` 도 의심 중이다
- [ ] **항공권** — `@여행메이트 오사카 항공권 찾아줘` → listCard 가 **보인다**
      · 안 보이면(말풍선 자체가 없으면) 그룹챗봇 렌더링 문제다. 로그에는 200 이 찍힌다
- [ ] **관광지** — `@여행메이트 도톤보리 맛집 알려줘` → 카드 + 줄을 누르면 구글맵으로 이동
- [ ] **카드 아래 고지** — `AI가 정리한 참고 정보예요…` 말풍선이 **항상** 같이 온다
- [ ] **날짜·인원 고지** — `오사카 호텔 4명 9월 22~24일` → 고지에
      `날짜·인원(4명, 9월 22~24일)은 반영되지 않았어요` 가 뜬다

## 7. 자주 헷갈리는 것

| 증상 | 어디를 보나 |
|---|---|
| 봇이 아무 말도 안 한다 | 폴백 블록 스킬 연결 · 봇 응답이 `스킬데이터` 인가 · 배포했는가 |
| `401` / 스킬 테스트 실패 | `X-Skill-Token` 헤더 값이 서버 `.env` 와 같은가 |
| `404` | 스킬 URL 오타 · 서버에 옛 버전이 떠 있음(1장의 curl 로 확인) |
| "30초 뒤에 다시" 만 나온다 | **[콜백 사용] 꺼짐** (3장) |
| 카드가 자동으로 안 온다 | 콜백 켰는데도면 검색이 1분 초과 (4장) |
| 버튼을 눌러도 반응 없다 | `MORE_BUTTON_STYLE=message` 로 내린다 (6장) |
| 항공권만 말풍선이 없다 | 그룹챗봇 렌더링. listCard 로 이미 바꿔놨으니 재발하면 보고할 것 |
